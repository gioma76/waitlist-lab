# waitlist-lab

Experimento de demanda: pagina estatica (`index.html`) con tres ideas de herramientas que **no existen todavia**. Mide cuantas personas dicen que usarian cada una (incidencias cuyo titulo empieza por `[interes]`; el titulo indica A, B o C). No se cobra nada, no hay analitica ni cookies ni scripts de terceros.
