# waitlist-lab

Experimento de demanda E4: pagina estatica (`index.html`) con tres **servicios piloto con precio visible** (por ahora solo se recoge interes; el servicio no esta operativo para cobro) (auditoria de accesibilidad web, pre-calculo y revision documental de expedientes CAE, borrador de la documentacion CBAM). Cada boton abre un formulario de incidencia de GitHub (`[piloto] 1.`, `2.` o `3.`). La respuesta "Si, pagaria el piloto a este precio" es un compromiso escrito: es lo unico que cuenta como observacion de disposicion a pagar. No se cobra nada, no se acepta ningun pago y no hay ninguna via de pago; no hay analitica, ni cookies, ni scripts de terceros.
